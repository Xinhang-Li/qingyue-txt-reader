# AI 划线辅助阅读 · 测试案例

测试素材：`sample.txt`（含「林冲」「高衙内」等人物与完整情节段落）。
联调用例通过本地 mock 服务验证（`tests/mock_ai_server.py`，实现 OpenAI 兼容接口）；
配置方法：⚙ 设置 → 接口 `http://127.0.0.1:8899/v1`，Key 任意非空，模型任意。

## 用例 1：划线人物 → 介绍
- 操作：在正文中用鼠标划选「林冲」二字，点击浮动工具栏「✦ 介绍」。
- 预期：右侧面板展开，顶部显示划线内容「林冲」，请求体包含「介绍这个人」与划线前后各约 350 字上下文；mock 下回答为 `[MOCK-介绍] …`；真实接口下为人物身份/背景介绍（200 字内）。

## 用例 2：划线剧情 → 概述
- 操作：划选一段完整剧情（如「陆虞候火烧草料场」相关段落，几十到几百字），点击「≡ 概述」。
- 预期：请求体包含「概述这段内容」；mock 下回答 `[MOCK-概述] …`；真实接口下为 3~5 句情节要点。

## 用例 3：划线后自由提问 + 追问
- 操作：划选任意内容，点击「？提问」，在面板输入框输入「他说话的对象是谁？」并发送；收到回答后再输入「他为什么要这么做？」追问。
- 预期：首个请求携带划线内容与问题；追问时 messages 中包含完整历史（user/assistant 交替），mock 下第二次回答为 `[MOCK-追问] …`。

## 用例 4：未配置 Key 的兜底
- 操作：清空 ⚙ 设置中的 Key，划线并点「介绍」。
- 预期：面板提示「还没有配置 AI 接口……」，不发起网络请求。

## 用例 5：接口报错兜底
- 操作：把接口填成无效地址（如 `http://127.0.0.1:9/v1`），划线点「概述」。
- 预期：面板显示「请求失败：…」，页面不卡死，可修正配置后重试。
